# Next Go Zap

Página de vendas do sistema **Next Go Zap**, desenvolvida para apresentar seus recursos de CRM e automação para WhatsApp Web e direcionar interessados ao agendamento de uma consultoria gratuita.

## Sobre o sistema

O Next Go Zap ajuda empresas e profissionais a organizar contatos, acompanhar oportunidades comerciais em um CRM Kanban e conhecer recursos de automação para a rotina no WhatsApp Web. A página apresenta os recursos do sistema, a versão Free, o funcionamento da consultoria e as informações comerciais necessárias para a aquisição ou demonstração da solução.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Google Analytics, Google Ads e Google Tag Manager
- Meta Pixel
- Cloudflare Web Analytics
